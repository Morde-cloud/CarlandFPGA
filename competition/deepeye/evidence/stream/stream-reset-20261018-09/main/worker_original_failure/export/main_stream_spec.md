## Admission and boundary rules

At a rising edge without rst/cancel, a transfer exists only when valid AND ready. Producer holds valid and associated payload stable during backpressure. cfg_ready iff no input block currently filling AND level<2; no same-cycle full-pop lookahead required. Reserve one tail slot on every cfg handshake, increment level and stat_cfg; latch count/E/tag. This includes invalid cfg. Config count1..128 and E in0,1,2,4,8 are valid. Invalid cfg immediately seals an error1 slot and accepts no samples. Error slots are ordered with successes; no bypass. No configuration and sample are consumed on the same edge when no prior filling block exists.

Valid cfg opens its slot for samples on subsequent edges, s_ready while filling only. Store each accepted sample; stat_samples increments for all accepted samples including the offending sample. s_last MUST equal (sample index==count-1). On early last or missing last at the declared final sample, stop accepting immediately, seal error2, discard that block's stored samples for encoding, and accept no trailing residue implicitly. Producer must start a new cfg for subsequent block data. Validly closed blocks seal for encoding. Silence/missing valid is not an error or synthesized input; partial blocks can wait indefinitely. cfg attempts while full/filling and sample attempts without s_ready do not count as accepted/rejected/dropped; no overflow drops. Do not add a drain-to-last state or timeout.

Only the oldest sealed slot can feed the actual core. Feed exact declared sample count with generated final last and stable data on core stalls. Early bad blocks never reach the core. Order preserved across success/error slots, concurrent ingress, pointer wrap and full/empty transitions. At most one encoder transaction exists. Once a slot retires its RAM may be reused; never read old unwritten data after reset/cancel.

## Output and counters

One metadata record per nonaborted admitted block, in order. Successful fields/bytes match unchanged core exactly, meta_tag echoes the admitted tag. Error metadata: original tag, error1 or2, count/E/k/bits/bytes allzero, raw1, no payload. Forward any actual core error as an error transaction with canonical metadata (such error should be unreachable from correctly validated sealed input). Metadata handshake precedes payload. While meta_valid&&!meta_ready, every metadata field remains stable. While m_valid&&!m_ready, data and last remain stable. No byte output for an error; exactly meta_bytes for success, last only on its final byte. No cross-block metadata/payload interleaving.

Retire success only on m_valid&&m_ready&&m_last and increment stat_ok. Retire error only on its metadata handshake and increment stat_error. Release slot/advance head/decrement level then. Simultaneous cfg allocation and head retirement must update occupancy correctly, without overwrite, double count or two competing nonblocking assignments. level counts all reserved partial, queued and actively encoding/emitting slots; values0..2 only. Counters are unsigned32 SATURATING, never wrap. cfg increments per admission, samples per handshake, ok/error per terminal transaction. Unsaturated accounting between resets: stat_cfg == stat_ok+stat_error+stat_aborted+level. Counters are internal diagnostic candidate ports, not a public register bank. Saturation loses numeric accounting information, never affects data flow; document/test boundaries.

## Reset/cancel

rst and cancel are synchronous activehigh, sampled at rising edges, with rst priority. Gate cfg_ready,s_ready,meta_valid,m_valid low immediately while either asserted; no handshakes on the flush edge. rst clears all slots/control/counters. cancel flushes all slots/core, clears level/filling/control, increments stat_aborted by PRE-flush level (saturating), and preserves other stats. Holding cancel for multiple edges counts each pending block once because level becomeszero. Simultaneous cfg/sample/output attempts are suppressed. Error pending or metadata already consumed but payload incomplete count as pending aborted blocks. A final byte suppressed by cancel never counts ok. Reset/cancel connect to actual core and cannot leave stale output after deassertion. RAM need not clear, but every subsequently observed location must be written by the new block.

External consumer MUST observe the same reset/cancel boundary and discard any partially consumed frame. No impossible atomic rollback of bytes already consumed, asynchronous kill/stopped-clock guarantee, CDC/RDC, or authenticated epoch claim. Fresh cfg/first block works after each flush. No reset protocol dependent on two-cycle clear unless explicitly justified and approved by main; interface above assumes rising-edge flush and ordinary next-cycle acceptance.
