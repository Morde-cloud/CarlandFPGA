## Interface and scope

`deepeye_crc16_byte` is a parameter-free, purely combinational module:

- Inputs: `crc_in[15:0]`, `data_in[7:0]`.
- Output: `crc_out[15:0]`.

It applies exactly one byte to an existing state. It has no clock, reset,
initial seed, storage, handshake, byte counter, packet policy, complement, or
output register. The caller supplies the packet-start state. For
CRC16/CCITT-FALSE, the caller seeds `16'hFFFF` before the first byte.

The mathematical parameters are polynomial `0x1021`, initial state supplied
by the caller (`0xFFFF` at packet start), no input or output reflection, and
`xorout=0`. The ASCII sequence `123456789` from seed `0xFFFF` therefore ends
at the standard check value `0x29B1`.

## Byte update

For input bit indexes 7 down to 0, the fixed eight-step recurrence is:

```
if state[15] xor data_in[index]
    state_next = (state << 1) xor 16'h1021
else
    state_next = state << 1
```

All shifts discard beyond bit 15. The module implements eight explicit named
combinational steps rather than delays, files, dynamic allocation, or a ROM.

This primitive does not parse packets, authorize lengths or types, accept a
profile, choose a seed, or freeze a public application ABI. Those concerns
remain outside this operation.

## Author verification

`tests/rtl/transport/tb_crc16_byte.sv` observes only the three public ports.
It covers the standard nine-byte vector, caller-held zero-length seed, all 256
byte values across six seed states, all 65,536 states for three selected
bytes, a 256-byte streaming comparison, and explicit MSB-versus-LSB input-bit
contrasts. It also embeds sixteen sampled constants generated by Python's
standard-library `binascii.crc_hqx`.

The main author sweep uses an MSB-first reference recurrence in the testbench.
That recurrence shares the same polynomial algorithm and is therefore an
author cross-check, not an independent oracle. The standard value is a
published check vector; the sampled library constants provide an external
implementation cross-check. Formal independence and the exhaustive
16,777,216 state/byte sweep remain main-owned.

`tools/transport/run_crc16_byte.py` creates a fresh author-owned attempt,
snapshots the exact RTL, testbench, runner, contract, and scope when available,
isolates temporary and simulator directories, executes real ModelSim 10.7,
and records versions, commands, returns, timeouts, raw stdout/stderr, and
hashes. It requires unique anchored transcript rows, the exact case sequence,
complete coverage counters, zero mismatches, and zero unexpected diagnostics.
