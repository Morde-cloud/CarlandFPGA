# Three-scan demo upload

`host147.py` accepts three retained B113 scan bundles in directories scan0, scan1 and scan2. Each contains request.json, source.bin and companion0.bin through companion3.bin. Keep those exact originals alongside the upload. The selected source format is the private 50 MHz relative-microsecond E4 frame already used by B77. The proposed 147 ingress uses operation-supplied context and a 1 Mbaud UART.

Use `python -B host147.py --originals PATH --base-seq N --out batch.json` to prepare the twelve input rows and dynamic session, epoch, tag and origin for a selected ingress. Supply a new output path. Input consists of three complete four-lane scans with a regular positive sample stride, valid fresh uint16 data and a uniform, representable opaque uint8 quality per channel. The original clock domain, per-scan source identities, original acquisition and source QPC and sub-microsecond remainder accompany each record. A separate producer must bind native sequence/tag and opaque data to the board operation. A owns the physical producer, load, register map and transfer.

Once four actual uploaded frames are available, add `--wire uart.bin` to the same command and use a new output path. Each packet has a twelve-byte little-endian E4 header, payload revision 2, and CRC16. The retained session, epoch, output sequence, channel, sample indices, tick stride, source tick and flag checks precede release of decoded points. The parser delegates Rice/RAW interpretation to the pinned existing decoder. For each point the result contains the wire-decoded value, separately retained original and signed error. Use max_absolute_error, sample_exact, actual frame modes and ledgers for the UI. Stored-code savings and total wire bytes include different costs. Retained-original bytes are counted separately because their transport is external. Compute measured latency from separately captured timestamps in an established common clock domain.

This path selects E=0 for the current three-point hardware composition. Demo phase 2 allows other quality choices in separately identified profiles. A value mismatch is exposed in the report. A CRC/layout/identity failure exits with an error. The report is observational, and downstream motion requires A/C operation authority. The currently selected singleton TRACE94 core has a different layout/operation and cannot consume this source interface without a reviewed integration and new matching build.
