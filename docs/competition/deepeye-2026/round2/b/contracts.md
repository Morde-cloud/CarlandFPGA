# v2 接口、因果闭环和预算修正

这是供 A 冻结的合同建议，非实现。执行器不属于本届；PL 的回读和电气测量是真实量，孪生位移/钻头角度是模型量，UI 永久标明两者。

传感缺线判据需实现：模拟输入加偏置，使开路落入预留无效码区，校准有效量程不占该码区；数字传感检查设备ID/读事务超时。没有硬件可检测断线条件时，不得承诺拔线必识别。

电气反馈建议：一个PL逻辑输出，经合适串联电阻接另一个输入，由独立计数器测周期；逻辑分析仪旁观。三档诊断载波建议HOLD/SLOW/ADVANCE分别25/50/100Hz，回采单位100微秒，模式和压缩profile可分别改变；HOLD有诊断载波不表示虚拟钻头前进。与Pmod电平、引脚共享和驱动能力由A按板卡原理图核定，不连接功率负载。不回采或回采不匹配时，孪生保持。它证明板端实际状态输出链，不是现实钻头位移。动画30fps只是渲染刷新率，不能成为反馈或时延证据。

推荐线帧上限32B；固定开销16B为前缀14B加尾CRC16：magic2/version1/type1/total_len1/session2/seq2/board_tick_ms4/flags1/CRC2。小端整数；CRC建议CRC-16/CCITT-FALSE（poly0x1021、init0xFFFF、refin/refout=false、xorout0，独立校验向量需冻结）。CRC覆盖前缀和载荷，不含CRC本身。长度16..32，版本/类型/长度白名单；无字节转义，滑动魔数+长度+CRC恢复，不得无上限分配或因载荷含魔数误截帧。丢字节、误魔数和超时另测。

|帧|总B|载荷建议|频率上限/含义|
|---|---:|---|---|
|SUMMARY|32|四均值8B、四极差8B；有效性在flags，tick为窗口末点|每8s一次；不是完整曲线，不保证窗内每点可重建|
|EVENT|20|事件码1B、级别1B、合并计数2B|每8s至多一线上事件，保留最高级与计数；本地记录全部|
|COMMAND|24|引用观测seq2B、目标epoch2B、profile1B、mode1B、最大观测年龄ms2B|每8s一次新命令；帧seq为命令ID，tick为引用板端tick|
|APPLIED|28|引用命令seq2B、生效epoch2B、实际profile1B、实际mode1B、窗口样本数2B、编码字节数2B、回采周期tick2B|每次新命令返回；tick为板端生效时刻；flags标明应用/拒绝/回采有效|

APPLIED在应用新epoch后至少完成一个新profile的16样本块及两周期回采才发送，携带该完整块的计数；禁止把旧profile计数标成新epoch。头部tick保留实际生效时刻，发送等待另计。以上计数字段为有界窗口增量；溢出置flag并在本地原始日志保留全宽值。回采单位及0/最大值含义在电气规格冻结。epoch与session换代时清空旧事务，重新握手；回绕前停止业务并重建会话，不把16位字段当永不回绕。profile字典及其哈希两端一致后才能RUN。重复命令只能重复返回第一次结果，不重新应用、不刷新观测年龄。超时或旧session命令拒绝；APPLIED回读与后续实际编码profile不一致算失败。UART重同步和初次会话握手在暂停态计量，不隐藏在稳定态预算。

8秒服务量=300×8/10=240B。常态104B用1040线bit=3.466667s；总换向guard预留0.2s，合计3.666667s，45.8333%。最多一次完整COMMAND+APPLIED重传52B后共156B，5.2+0.2=5.4s，67.5%；余2.6s用于OS抖动和暂停态诊断，增强趋势只有预约后才进入。若量得guard更长或需要额外心跳，必须重算。不能把剩余预算全部视为可持续吞吐。

8秒是限流统计周期，不是强制等待周期。PL为仲裁主站，帧边界结束后依次允许事件、PC应答窗口、反馈；PC只在grant窗口发送。grant语义由既有flags携带，无额外线上帧。发送新命令前排空不必要的诊断，最大单帧阻塞32×10/300=1.066667s。一次触发路径的序列化算例为在发32+事件20+命令24+反馈28=104B，再加采样≤10ms、软件/FPGA/渲染预算及guard；它不是Windows一般最坏时延保证。持续过载进入HOLD并报告遗漏，不无限重传。

数据年龄门建议为16s，仅供冻结前回放验证；普通摘要最旧样本可达8s加排队，故不能套用2s淘汰。事件路径目标P99≤8s、max≤12s，普通曲线另报数据年龄。时延起点为实际采集或变化时刻，终点分开记PL_APPLIED、电气回采、UI第一帧；不填写“机械响应”。双设备计时用同trace与板端tick，给同步误差，UI帧由日志关联独立屏幕录制。

硬否决保留：回放冒充真实传感、仿真冒充实板、PC回显冒充PL回读、绕低速链路偷取业务真值、未测硬件加速却宣称NPU/ROCm、标签泄露。纯无执行器数字孪生、CPU推理和非2026.1工具不再是v2否决项；其他版本仍须说明和可复现。
