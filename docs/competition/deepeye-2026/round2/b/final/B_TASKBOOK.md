实际读到 A 群公告对应 PR17 `2c424a9`，C 群公告分别对应 PR14 `97812df` 与 PR15 的定稿 `3d428cd`。查询时 PR15 已追加至 `17e81c5`，因此本次读取其当前固定 head：定稿 TASKBOOK/PROTOCOL/tasks 三文件均与原定稿 manifest 匹配，后加的 A v3 评析另列来源。C 的两份交付不是两名独立队员，也不增加“三机五案”的计数。

PR15 的后续评析明确将 final/ 下的 v2 文件保留为历史稿，并接受 A v3 的 ROCm/物理任务门及 PGA 建议。因此“v2不依赖ROCm”不能当作 C 当前立场；PR14 的舵机及 C 全包 RTL 分工也不能覆盖更新后的无机械执行器约束和 A/B/C 分工。

B 常驻质量会话已完成第二轮：PR16 保留融合评析和对 A 根稿的定向复核。旧 ACK 续 TTL 与无合法第二重试槽两项 P0，已在 A `2c424a9` 的规范中修正；[B 关闭意见](https://github.com/carolwjade/CarlandFPGA/pull/17#issuecomment-6152628524)仅关闭文档问题，实际状态机、时槽和板测仍待运行。本轮复用该记录，不重做五案或旧基础板测。

## 三、R03 向 B 交接前必须冻结的内容

以下是 A 公共接口的具体输入清单。B可提出向量和审核意见，不在 B 目录制造另一套公共 ABI。

1. `interface.json`、`registers.csv`、向量及其 SHA：端序、CRC范围、长度、phase/fault/quality 数值、低位序号比较范围、会话/epoch回绕规则；TRACE 的块描述、锚点、Rice/RAW选择、padding及终止/长度规则必须逐位确定。
2. `slot_profile` 数值表及 SHA：主请求/应答/重试/配置槽的绝对偏移、超时、最大帧长、空等和 USB/处理余量；禁止把“204B有预算”当作完整时序证明。bit13+15允许同键重试，bit14互斥，无授权只等下一合法槽。
3. 握手、首 ACK 丢失、重复/旧会话/异负载同键、配置块边界生效、GAIN模拟测量、断链/复位等正反例。CONTROL 的首次发送时刻与原 TTL 保持不变，重发 ACK 必须重新取当前状态和剩余 TTL。
4. 输入时钟/复位、XADC与DMA位宽/顺序/TLAST、背压和单侧复位契约；PYNQ版本按 A 实测环境冻结，不能依据一份草稿自动升级镜像。
5. 精确工作目录/文件归属、task/version/work_id、源码及输入哈希、独立回解责任 C、A 实板回传格式。现有20卡 JSON 是计划，不是已经运行的 pipeline 或分配完成的执行租约。

当前未取得上述 R03 实现产物与通过证据，故 B01 起始依赖尚未满足。本补充只做可独立完成的规划核对，不用旧候选字段提前实现。R03 一旦完成并登记归属，常驻流程接续 B01，无需再次询问人类一般性设计细节。

## 五、接口和预算的验收重点

按 A abi_v2，基础窗144B、量程替代窗140B、配置最坏窗200B、控制重试窗204B；300baud8N1下分别加0.2秒规划guard后占62.5%、60.833%、85.833%、87.5%。该算术已在先前评审中检查，本轮不重演旧预算试验。实际字节流、数值槽边界、空等和任意滑窗由R03/B04新增执行证据证明；guard超规划须重算。

TRACE在高负载窗禁发；量程GAIN替代CONTROL槽，不同时追加。首版在线AI不使用本地queue隐蔽输入。ACK/STATE动态回采，host deadline同时受首次发送+原TTL上限约束；capture无效、旧会话或期限过后不得孪生积分。低16位序号、epoch回绕、各类拒绝码必须在R03明文冻结后实现。
