# Integration for A

Use the host tool from competition/deepeye/tools/diagnostic/demo_multiscan147. Supply three original B113 scan directories and one nonwrapping base frame sequence. Its normal CLI emits the batch operands and selects the operation's session, epoch, tag, origin, lane values, QPC and native indices. Preserve request/source/companion bytes for independent comparison. Background, stale, saturated, held or malformed records cannot be substituted for the fresh-only format.

The proposed RTL interface and refusal codes are in competition/deepeye/fpga/diagnostic/demo_multiscan147/INTERFACE.md. A future owner-selected bus adapter must expose the ARM/configuration fields, transfer each input once through valid/ready, retain the four result handshakes and drain actual up_valid/up_ready bytes. Retain framing/overrun/false-start/refusal/abort evidence, close ambiguous transactions and do not replay them. The simulated TX-to-RX connection is local to the testbench. A board port, addresses, approved build closure and same-build BIT/HWH/identity must be separately established. No board command is included in this handoff.

In an authorized acquisition, preserve four concatenated packets as uart.bin. Call host147.py --originals DIR --base-seq N --wire uart.bin --out NEW.json. The PC result reports observed coding mode, original and reconstructed uint16 values, per-point signed error, source chronology and separate stored-code/wire/retained-source bytes. Keep real end-to-end timing and boot/build provenance in the calling operation record. For phase 2 the UI may show a RAW frame or nonzero error. CRC/layout/sequence/clock failures are refusals.
